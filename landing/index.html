Data gedung sebagai GeoJSON, dari satu binary Go.

REST API kecil (Go + Fiber) yang menyajikan dua gedung contoh sebagai FeatureCollection GeoJSON — siap dipanggil aplikasi peta 3D. Tanpa database, tanpa auth, tanpa konfigurasi.

Filter type yang tidak cocok gedung mana pun mengembalikan "features": [] — array kosong, tetap GeoJSON valid. Route tak dikenal → HTTP 404.

  


  

    
Kenapa API ini?

    

      
GeoJSON valid
FeatureCollection + Polygon sesuai RFC 7946, koordinat [longitude, latitude]. Filter tanpa hasil tetap mengembalikan array kosong, bukan null.

      
Satu binary, tanpa setup
go run . atau satu image Docker. Port lewat env PORT, default 8080.

      
Jujur soal data
Datanya mock statis dua gedung contoh — dinyatakan di README, bukan diklaim sebagai data survei. Tanpa database, tanpa endpoint tulis.

    

  


  

    
Mulai

    
Butuh Go 1.26+ (diuji dengan Go 1.27) atau Docker.

    
$ git clone https://github.com/dezzorigin/go-geojson-api.git
$ cd go-geojson-api
$ go run .
# http://localhost:8080

$ docker build -t go-geojson-api .
$ docker run -p 8080:8080 go-geojson-api
$ curl -s localhost:8080/api/v1/health
{"status":"healthy"}
